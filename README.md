# 音乐收听日历

在日历上查看每天听过哪些歌曲，以及每首歌曲的收听时间，显示精度到分钟。

数据目标优先覆盖全部播放历史。在现有接口无法返回完整历史时，以网易云音乐服务端提供的**首次播放时间**建立个人音乐日历，同时保留以后接入完整播放事件的能力。

## 第一阶段

- 按月浏览日历，选择一天查看当天首次听到的歌曲。
- 展示歌名、歌手与北京时间 `HH:mm`；保存服务端原始时间戳。
- 采集单曲“回忆坐标”，保存首次收听时间和累计播放次数。
- 对缺失数据、查询失败和来源覆盖范围保留明确状态。
- 数据存储在本机，支持重复采集、去重和导出。

“首次播放”视图表示服务端记录的初次收听时间，不代表当天完整播放记录；同一首歌之后的重播不会凭空生成。

## 当前状态

仓库已初始化，已完成关键接口的小规模账号实测；应用和采集器尚待实现。

- `/music/first/listen/info`：已验证能返回部分歌曲的首次收听毫秒时间戳和累计播放次数，部分歌曲返回空对象。
- `/record/recent/song`：能返回近期播放时间，但本次只拿到 300 个不同歌曲的记录，完整性未证实。
- `/listen/data/today/song`：能返回今日歌曲及其最近播放时间，使用秒时间戳。
- 月榜、年报、周报可用于补充统计，不作为完整播放事件导入。

详见 [产品范围](docs/PRODUCT.md) 与 [接口验证](docs/API_FINDINGS.md)。

## 数据与凭据

账号凭据通过运行环境或本机登录态提供。个人听歌数据、数据库、接口原始响应和 Cookie 均排除在版本控制之外。
