# 初听 · 音乐初听日历

每首歌，都有第一次听见的那天。

「初听」读取网易云音乐「回忆坐标」里的初听时间，把每首歌放回你第一次听到它的那一天，做成一本可以翻看的月历。它运行在你自己的电脑上，数据只存在本机。

> 初听日历只记录每首歌的**第一次**播放，不是你每天完整的听歌记录。

## 能做什么

- **按月翻看**：日历格子的颜色越深，那天遇见的新歌越多；点开某一天，按时间（精确到分钟）列出当天第一次听到的歌。
- **搜索**：跨所有月份搜索歌名或歌手。
- **歌曲详情**：初听时间、累计播放次数、数据来源，以及原始毫秒时间戳；多次查询结果不一致时也会标出来。
- **同步歌曲**：从最近播放、听歌排行、喜欢的歌曲和你创建的歌单里找出歌曲，再逐首查询初听时间。可以分批或一次全部同步，随时暂停、接着同步，失败的歌曲下次会自动重试。
- **同步概况**：已发现多少首、查了多少首、找到多少条初听时间、多少首暂无记录或查询失败，一目了然。
- **导出**：JSON / CSV，保留原始毫秒时间戳和时区。
- **浅色 / 深色**：跟随系统外观自动切换，手机上也能正常浏览。

## 快速开始

需要 macOS 或 Linux、Python 3.9+（含时区数据）和 Node.js 22+。

```sh
git clone https://github.com/InkCitrus/netease-listening-archive.git
cd netease-listening-archive
npm ci --ignore-scripts
npm start
```

然后在浏览器打开 <http://127.0.0.1:8767>。

在 macOS 上也可以直接双击仓库里的 `start.command`，第一次启动会自动安装依赖。

### 登录

- **macOS**：先在官方网易云音乐客户端登录，「初听」会以只读方式沿用它的登录状态。
- **其他系统**：通过环境变量 `NETEASE_COOKIE` 提供你自己的 Cookie，不需要写进代码。应用不会自动读取 `.env` 文件。

登录只在同步时用到。已经同步下来的数据，离线或登录过期后照样能浏览。

## 同步歌曲

在网页右上角点「同步歌曲」，选择这次查询多少首即可。已经查过的歌会自动跳过；选「全部未查询的歌曲」会一次处理完剩下的。请求逐个发送，每首之间停顿约 0.9 秒。

也可以用命令行同步（先关掉使用同一数据目录的网页服务）：

```sh
python3 -m music_calendar sync --limit 200                 # 查询 200 首
python3 -m music_calendar sync --limit 0                   # 查询全部未查询的歌曲
python3 -m music_calendar sync --limit 200 --retry-empty   # 同时重查之前没有记录的歌曲
```

加 `--no-playlists` 可以跳过你创建的歌单。每次同步都会重新查找新增的歌曲；查询失败的歌曲下次会自动重试，之前没有记录的歌曲需要勾选「重新查询」或加 `--retry-empty`。

## 数据保存在哪里

默认保存在项目里的 `data/` 目录（已被 Git 忽略）：

- `calendar.sqlite3`：账号、已发现的歌曲、初听时间、来源、时间差异和同步进度。
- `raw/`：接口的原始响应，方便日后核对。
- `session-tmp/`：运行时的临时文件，不保存登录 Cookie。

备份时请先关闭程序，再复制整个 `data/` 目录；如果程序正在运行，请用 SQLite 在线备份，不要直接复制正在写入的数据库文件。

想换一个数据目录或端口：

```sh
python3 -m music_calendar --data-dir /path/to/archive serve --port 8768
```

服务只监听 `127.0.0.1`，同一个数据目录同时只能有一个网页或命令行进程在用。

## 需要知道的边界

- 从这些来源找到的歌曲，不一定涵盖你听过的全部歌曲。
- 接口查不到初听时间，不代表你从没听过这首歌。
- 累计播放次数只作为统计展示，不会被拆成虚构的播放记录；重复同步也不会多出初听条目。
- 如果多次查询得到的初听时间不同，所有版本都会保留，日历显示最早同步到的那一个。

之后如果要记录同一首歌的每一次播放，需要接入可靠的播放事件或已有日志；目前还没找到能导出账号完整逐次播放记录的接口。

## 开发

Python 标准库 + SQLite；Node 子进程只调用白名单内的只读接口；前端是原生 HTML / CSS / JavaScript，无需构建。接口依赖固定为 `4.41.1`，完整性校验见锁文件。

```sh
npm test
node --check web/app.js
node --check music_calendar/provider.cjs
```

测试使用模拟接口和临时数据库，不读取真实 Cookie；HTTP 用例使用临时的本机端口。
